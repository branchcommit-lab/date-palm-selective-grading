# Data and code availability

## Data availability

The source photographs are available in *Size-Based Date Fruit Dataset for Classification* (Mendeley Data, Version 1, https://doi.org/10.17632/d986hyr2kb.1). The source-group split registry, frozen prediction records, experimental parameters and numerical result tables for this study are available at https://github.com/branchcommit-lab/date-palm-selective-grading. The synthetic alteration records represent controlled transformations of the original images rather than observations of naturally occurring defects.

## Code availability

The statistical analysis code and scripts for regenerating the seven main figures, seven main tables and supplementary results are available at https://github.com/branchcommit-lab/date-palm-selective-grading. The commands `python run.py results` and `python publication/rebuild_manuscript_assets.py` reproduce the published numerical analysis and visual displays from the recorded predictions. Fresh image-level inference and independent retraining additionally require source photographs and model weights, which are not distributed in this repository.
