# Model checkpoint inputs

The original trained model binaries are not included in this repository. The file
`manifest.json` lists expected SHA-256 identifiers and sizes for the principal
model weights. Additional C3 checkpoint identities are recorded in
`data/verification/C3_CHECKPOINT_INVENTORY.json`.

The published results and figures can be regenerated without the checkpoints
using the frozen experimental prediction records. Fresh model inference or
training requires obtaining the exact model weights, original photographs, masks
and intermediate inputs from the research owners or other authorized sources.
There is no public download URL for those model weights in this repository.
