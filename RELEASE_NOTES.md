# Release 1.0.2

## Maintenance update

Notebook execution messages and analysis-source section labels were standardized for the public repository. The experimental implementations, observation-level records and reported numerical results are unchanged. Integrity metadata were refreshed for the revised files.

## Included data and implementations

- Frozen original, benign and synthetic-alteration predictions for C1 and C2.
- Twelve four-view, twelve cultivar-holdout and nine size-class-holdout evaluation records for C3.
- Statistical reconstruction of C1/C2/C3 comparisons from the released observation records.
- Regeneration of seven numbered manuscript figures, seven main tables and three supplementary tables.
- Experimental methods, inference modules, executable checks and SHA-256 integrity metadata.

## Computational scope

Recorded-prediction analyses and publication displays run without model weights. The original photographs, intermediate image benchmarks, and model-weight binaries are not distributed; fresh image inference and independent training therefore require additional source material.

## Validation

The statistical output, publication assets, package integrity and execution-scope tests are covered by commands in `README.md`. All result tables derive from the distributed frozen numerical records.
